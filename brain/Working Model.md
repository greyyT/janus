# Working Model

Janus's beliefs about how the user actually works. Planning, dispatch, and capacity estimates rely on them. They describe; they are not rules (`brain/Precedents.md`), project direction, or authority (`brain/Grants.md`).

Dream maintains this page from evidence and every change reaches the user through the dream PR. A belief needs the user's explicit statement, or the same behaviour seen repeatedly under similar conditions; a single observation is not a belief. Edit or retire a belief that new evidence contradicts; never delete one.

## Entry format

```md
### Short belief

- belief: one checkable sentence
- applies to: planning | dispatch | capacity | communication | …
- evidence: dated links to journals, tickets, or transcript sessions, and earlier dream PRs; `; via dream PR <branch>` when Dream wrote it
- since: YYYY-MM-DD
```
